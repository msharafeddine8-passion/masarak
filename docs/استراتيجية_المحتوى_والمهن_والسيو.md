# المرحلة 2 — نظام رحلة الطالب

مسار موجَّه من 7 مراحل. كل مرحلة = **صفحة محور** + **أداة** + **محتوى** + **CTA للخطوة التالية**، وتكتب في ملف الطالب ليصير التالي مخصّصاً.

| المرحلة | حالة الطالب | ماذا يقدّم مسارك | الأداة الرئيسيّة | الخروج → |
|---|---|---|---|---|
| **0. تائه** | "ما عندي فكرة شو بدّي" | طمأنة + اختبار توجيه | **Career DNA** + مطابقة-تخصّص | → م.1 |
| **1. اكتشاف الذات** | "شو بحبّ / شو شاطر فيه؟" | شخصيّة + اهتمامات → قائمة تخصّصات | DNA → تخصّصات | → صفحات التخصّص |
| **2. اختيار التخصّص** | "أي مجال؟" | **خرائط مهنيّة للتخصّص** (المرحلة 3) | اختبار مطابقة-تخصّص | → الدولة |
| **3. اختيار الدولة** | "وين؟" | مطابقة-دولة (تكلفة، لغة، فيزا، وظائف) | مطابقة-دولة + حاسبة تكلفة | → الجامعات |
| **4. اختيار الجامعة** | "أي جامعة؟" | مقارنة + ملاءمة القبول | مقارنة + مقدّر القبول | → المنح |
| **5. التمويل** | "بقدر أتحمّل؟" | مطابقة منح + أهليّة | فاحص أهليّة + حاسبة تكلفة | → التقديم |
| **6. التقديم والتحضير** | "كيف بدخل؟" | مستندات، CV، SOP، IELTS، **فيزا** | CV/cover-letter/مقابلة + متتبّع التقديم | → قدّمت ✅ |

**الآليّة:**
- شريط **"رحلتك" (0–6)** دائم على لوحة الطالب، مدفوع بإشارات الملف (عمل DNA؟ حفظ تخصّص؟ اختار دولة؟ يتتبّع منح؟).
- كل صفحة مرحلة تنتهي بـ**فعل تالٍ واحد** واضح (لا طرق مسدودة).
- "تابع من حيث توقّفت" عند العودة — مُمكِن أصلاً عبر `student_profiles` + المحفوظات.

# المرحلة 3 — نظام الربط المهني (القاطرة)

**حوّل كل تخصّص إلى صفحة قرار.** أعلى حركة قيمة (محتوى+SEO+منتج)، وأكبر فجوة حاليّة (التخصّصات بلا صفحات تفصيليّة).

## 3.1 مخطّط صفحة التخصّص (`/majors/[slug]`)

| الكتلة | المحتوى | المصدر |
|---|---|---|
| ما هو؟ | شرح بعربيّة بسيطة، "هل يناسبك؟" | محتوى `majors` جديد |
| المهارات المطلوبة | قائمة مهارات صلبة + ناعمة | منسّق |
| ملاءمة الشخصيّة | أنماط RIASEC التي تنجح (ربط بـ DNA) | ربط بـ `personality_type` |
| المواد التي ستدرسها | نظرة سنة-بسنة | منسّق |
| المهن بعد التخرّج | مسمّيات وظيفيّة + روابط `/careers/[slug]` | ربط تخصّص→مهن |
| الرواتب (عالميّاً) | مبتدئ/متوسّط/كبير حسب المنطقة (خليج/شام/مصر/أوروبا/أمريكا) | `salary_ranges` جديد |

| المنح ذات الصلة | مفلترة بالمجال | `scholarships.fields` |
| الجامعات ذات الصلة | أفضل الجامعات المقدّمة له | `universities_global` |
| المستقبل | اتجاه الطلب + **أثر الذكاء الاصطناعي** (🟢 ينمو / 🟡 يتحوّل / 🔴 مهدّد) | منسّق، عالي المشاركة |
| CTA القرار | "خُذ اختبار مطابقة-التخصّص" / "قارن الدول" | روابط الأدوات |

## 3.2 نموذج البيانات (إضافي — بلا كسر)

```
majors(id, slug, name_ar, name_en, category, summary_ar, skills[], riasec_types[],
       subjects[], ai_impact ENUM('grows','shifts','at_risk'), demand_score int,
       future_outlook_ar, status)
major_careers(major_id, career_slug)                  -- M:N → المهن الموجودة
major_salary(major_id, region, level, min, max, currency)
major_countries(major_id, country_code, rank_note)    -- "أفضل الدول"
```

## 3.3 لماذا تنجح
- **SEO:** تفتح "وظائف بعد [تخصّص]"، "راتب [تخصّص]"، "هل [تخصّص] له مستقبل"، "[تخصّص] أم [تخصّص]" — حجم هائل.
- **المنتج:** الجسر المفقود بين *الاهتمام* (DNA) و*الفعل* (التقديم).
- **الربط الداخلي:** التخصّصات تصير المحور الذي يربط DNA → مهن → دول → جامعات → منح.

# المرحلة 4 — استراتيجية محتوى الـ SEO (600 قطعة)

**المقاربة:** عناقيد برمجيّة (قابلة للتوليد) + أدلّة رئيسيّة مكتوبة يدويّاً. تحت: **نظام العناقيد + الصيغ** (ليولّد الفريق الأعداد بدقّة) + **أعلى العناوين أولويّة** للبدء. كلّها عربيّة-أولاً، مع نسخ إنجليزيّة لاحقاً للـ hreflang.

> ترميز الصيغة: `[تخصّص]`×32، `[دولة]`×~25 (عربيّة + أهمّ دول الدراسة)، `[مستوى]` (بكالوريوس/ماجستير/دكتوراه).

## 4.1 — 300 مقال عالي الزيارات (10 عناقيد)

| العنقود | الصيغة | العدد | عيّنات |
|---|---|---:|---|
| تخصّص → مهنة | "ماذا بعد دراسة [تخصّص]؟ الوظائف والرواتب" | 32 | "ماذا بعد الطب؟"، "وظائف خريجي علوم الحاسوب" |
| هل يستحقّ | "هل تخصّص [X] له مستقبل؟ (2026)" | 32 | "هل العمارة لها مستقبل؟" |
| تخصّص مقابل تخصّص | "[أ] أم [ب]؟ كيف تختار" | ~40 | "طب أم صيدلة؟"، "CS أم هندسة برمجيات؟" |
| الرواتب | "كم راتب [تخصّص] في [منطقة]؟" | ~40 | "رواتب المهندسين في الخليج" |
| أثر AI | "هل الذكاء الاصطناعي سيلغي وظيفة [مهنة]؟" | ~30 | "هل AI سيلغي المحاماة؟" |
| "أفضل تخصّص لـ…" | "أفضل تخصّص لمن يحبّ [اهتمام]" | ~30 | "أفضل تخصّص لمن يحبّ الأحياء/الرسم" |

## 4.2 — 100 دليل "الدراسة في [دولة]"

لكل دولة (×~25) **عنقود صغير من 4**: `(1) دليل الدراسة في [دولة]` · `(2) الدراسة في [دولة] مجاناً/تكلفة` · `(3) الدراسة في [دولة] بدون IELTS` · `(4) منح [دولة] للعرب`. → 25 × 4 = **100**.

**دول الأولويّة (ابدأ فيها):** ألمانيا (مجاناً!)، تركيا، كندا، فرنسا، بريطانيا، أمريكا، ماليزيا، هولندا، إيطاليا، السويد، الإمارات، السعوديّة، قطر، مصر، الأردن، روسيا، المجر، بولندا.

**أعلى نيّة (اكتبها الأسبوع 1):**
- "كيف تدرس في ألمانيا مجاناً (خطوة بخطوة) 2026"
- "أرخص الدول للدراسة في الخارج للعرب"
- "الدراسة في الخارج بدون شهادة IELTS"
- "الدراسة في الخارج خطوة بخطوة: الدليل الكامل"
- "كيف تدرس في تركيا بمنحة كاملة"

# المرحلة 5 — تحسينات تجربة المستخدم / المنصّة

## 5.1 الصفحات الناقصة
- `/majors/[slug]` (الخرائط المهنيّة — المرحلة 3) 🔴 الأولويّة القصوى
- `/scholarships/[slug]` (لكل منحة + "كيف تفوز") + **backfill للـ slugs**
- `/study-abroad/[country]/cost`، `/free`، `/no-ielts`، `/scholarships` (صفحات نيّة)
- `/start` — محور دخول الرحلة (المرحلة 2)
- `/support/*` — محور المحتوى العاطفي/القراري
- `/compare` — مقارنة جامعات/دول/تخصّصات جنباً إلى جنب

## 5.2 التنقّل (قراري، لا كياني)
```
ابدأ رحلتك  |  اكتشف نفسك (DNA/مطابقة-تخصّص)  |  التخصّصات والمهن
الدراسة بالخارج (حسب الدولة)  |  المنح  |  الجامعات  |  الأدوات  |  المدوّنة
```
التنقّل الحالي يسرد *كيانات*؛ صدّر *القرار* بدالها.

## 5.3 ترقية الفلاتر
- الجامعات: + دولة، لغة التدريس، شريحة الرسوم، فيها منح، التصنيف.
- المنح: + دولة، مستوى، مجال، تمويل (كامل/جزئي)، الموعد، بدون IELTS.
- التخصّصات: + ملاءمة RIASEC، أثر AI، شريحة الراتب، الطلب.

## 5.4 نظام التوصية
- "لأنّك حصلت على **Investigative** في Career DNA → هذه 5 تخصّصات / 3 دول / 8 منح."
- مدفوع بـ `personality_type` + المحفوظات + الدولة. يظهر على اللوحة + كل صفحة كيان ("طلاب مثلك شاهدوا أيضاً…").

## 5.5 استراتيجيّة الربط الداخلي
- **محور وأذرع:** صفحة التخصّص = محور → تربط مهنه، راتبه، دوله، منحه، جامعاته. كل كيان يربط *رجوعاً* لتخصّصه.
- كل مقال مدوّنة يربط ≥3 صفحات كيان + 2 مقال شقيق.
- كتل "ذات صلة" تلقائيّة من `field`/`country_code`/`riasec` المشتركة.

## 5.6 إعادة تصميم الصفحة الرئيسيّة
استبدل "دليل الـ X" بـ**تدفّق قرار**:
1. البطل: *"مش عارف شو تدرس؟ خلّينا نساعدك تقرّر."* → CTA لـ Career DNA.
2. 3 مسارات: "اكتشف تخصّصك" / "ادرس بالخارج" / "دوّر على منحة".
3. "رحلتك" (للمسجَّلين).
4. دليل اجتماعي + أدلّة رائجة (روابط SEO داخليّة).

# المرحلة 6 — أدوات قرار الطالب

لكل أداة: **تدفّق المستخدم · البيانات المطلوبة · الواجهة · منطق قاعدة البيانات.**

### 1. اختبار توصية التخصّص
- **التدفّق:** 12–15 سؤال (اهتمامات/قوى/أسلوب عمل) → أفضل 3 تخصّصات + نسبة ملاءمة.
- **البيانات:** الأجوبة → متّجه RIASEC؛ `majors.riasec_types`.
- **الواجهة:** سؤال-بالشاشة، شريط تقدّم، بطاقات نتيجة → صفحات التخصّص.
- **القاعدة:** إعادة استخدام محرّك Career DNA؛ `match = cosine(user_vector, major_vector)`؛ تُخزَّن في `student_profiles.personality_type` (موجود).

### 2. نظام مطابقة الدولة
- **التدفّق:** ميزانيّة + لغة + مجال + أولويّات (تكلفة/أمان/وظائف/سهولة فيزا) → دول مرتّبة.
- **البيانات:** `countries` (تكلفة، لغة، صعوبة فيزا، عمل بعد الدراسة).
- **الواجهة:** منزلقات + رقائق → بطاقات دول مرتّبة مع "لماذا".
- **القاعدة:** درجة موزونة لكل دولة؛ تحتاج جدول `country_facts` (شريحة كلفة، لغات[]، درجة فيزا، حقوق عمل).

### 3. فاحص أهليّة المنح
- **التدفّق:** جنسيّة، مستوى، معدّل، مجال، IELTS؟ → "أنت مؤهَّل لـ N منحة".
- **البيانات:** `scholarships` (+ إضافة `min_gpa`، `nationalities[]`، `requires_ielts`، `level`).
- **الواجهة:** نموذج قصير → قائمة مؤهَّلة + تلميحات "الشرط الناقص".
- **القاعدة:** استعلام فلترة؛ احسب مسبقاً عدد المؤهَّل للصفحة الرئيسيّة.

### 4. حاسبة تكلفة الدراسة *(موجودة — ترقية)*
- **أضف:** دولة + مدينة + نمط حياة → رسوم + معيشة + فيزا + طيران؛ قارن 2–3 دول؛ "مع/بدون منحة".
- **القاعدة:** `country_facts.living_cost`، `universities_global.tuition_min/max`.

### 5. مقدّر احتماليّة القبول
- **التدفّق:** معدّل + علامات اختبارات + جامعة هدف → "محتمل / طموح / آمن".
- **البيانات:** `universities_global.acceptance_rate` + العلامات المطلوبة (أضف `min_grade`).
- **الواجهة:** مقياس (أخضر/أصفر/أحمر) + "حسّن فرصك" + تسويق متقاطع للمنح.
- **القاعدة:** `band = f(علامة الطالب مقابل عتبة الجامعة، acceptance_rate)`؛ معادلة شفّافة (سمِّها تقدير، لا ضمان).
